## videoeditor

### 1. Клонирование проекта из Github

Перед клонированием выполните возврат в корневую папку вашего текущего пользователя
```shell
cd ~
```
клонируем
```shell
git clone https://github.com/trykimu/videoeditor.git
```
переходим в папку с клонированным проектом
```shell
cd videoeditor
````
