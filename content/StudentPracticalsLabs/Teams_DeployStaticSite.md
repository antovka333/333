## Командная работа над статическим сайтом (HTML+CSS+JS) с CI/CD (Deploy) на GitHub Pages

**Цель** — научиться самостоятельно **деплоить** "живой" сайт на GitHub Pages через **настоящий CI/CD**, видеть историю деплоев в интерфейсе GitHub и открывать сайт по кликабельной ссылке.

- Название команды
- Примерный состав команды:
    - Лидер (Создание репозитория, приём в него участников команды (Collaborator), координация)
    - Девопс-инженер (разработка и создание CD/CD-инфраструктуры)
    - Программист 1 (код сайта HTML+JS)
    - Программист 2 (код сайта HTML+JS)

**Задача** - при помощи нейросети создать статический сайт **HTML+CSS+JS** на "живой" URL через **GitHub Pages**, **Environments** и **Deployments** с красивым дизайном и анимацией на JS.

[Пример проекта](/content/DevOps/CI_CD/Pipelines/CI_Deploy_GitHub_Pages.md)

- Cайт должен содержать не менее **пяти** страниц
- После создания сайта и его деплоя на **GitHub Pages** необходимо создать `README.md` с описанием проекта (Markdow+Картинки+списки+Структура проекта в виде Mermaid-диаграммы)
- Главное окно репозитория проекта должно содержать прямые кликабельные ссылки на сайт проекта (в **About**), **Deployments** (история деплоев) и **Environments** (https://github.com/<ВАШ-USERNAME>/hello-pages/settings/environments)
- Сделайте **три** обновления сайта (отредактируйте какие-нибудь его страницы) с коммитами и пушами.
- В **Deployments** проекта должно быть не менее 3-х **deployments**
- Обязательно равное участие всех членов команды в проекте, которое определяется по количеству и качеству коммитов!
