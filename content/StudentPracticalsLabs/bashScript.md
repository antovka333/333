1. Напишите скрипт, который спрашивает имя пользователя и выводит приветствие (Напишите скрипт, который спрашивает имя пользователя и выводит приветствие.);
1. Калькулятор суммы (Создайте скрипт, который запрашивает два числа и выводит их сумму);
1. Проверка четности числа (Напишите скрипт, который определяет, является ли число четным или нечетным);
1. Скрипт - создатель структуры проектов (создайте скрипт, который делает структуру папок для веб-проекта)
    - Пример структуры:
    ```markdown
    my-project/
    ├── index.html
    ├── css/
    │   └── style.css
    └── js/
        └── script.js
    ```
1. Счетчик строк в файле (Напишите скрипт, который подсчитывает количество строк в указанном файле);
1. Генератор паролей (Создайте скрипт, который генерирует случайный пароль длиной 8 символов);
1. Поиск файлов (Напишите скрипт, который ищет файлы по расширению в текущей директории);
1. Проверьте все скрипты на выполнение командой `sh script.sh` в **Git-Bash** (в powershell они не работают!)
1. Оформите красивый **README.md** в формате **Markdown**. Этот файл должен содержать краткую информацию о вашем задании.
1. В Ubuntu WSL создать Bash-скрипт для анализа популярных репозиториев на GitHub с отображением статистики в цветном формате.
    - Базовый функционал:
        - Скрипт принимает имя репозитория как аргумент (например, ./github-stats.sh tensorflow/tensorflow)
        - Выводит: название, количество звёзд, количество форков, количество открытых issues
        - Использует GitHub API (публичный эндпоинт)
    - Цветной вывод:
        - Звёзды — жёлтым цветом
        - Форки — зелёным
        - Issues — красным (если > 100), иначе жёлтым
    - Обработка ошибок:
        - Проверка наличия curl и jq
        - Обработка ошибок API (неверный репозиторий, превышение лимитов)
        - Вывод понятных сообщений об ошибках
        Пример вывода:
        ```
        ╔════════════════════════════════════════╗
        ║  🚀 GitHub Repository Analyzer            ║
        ╚════════════════════════════════════════╝

        📦 Репозиторий: tensorflow/tensorflow
        ⭐ Звёзды:       182,347  (⭐)
        🔀 Форки:        73,891   (🔀)
        🐛 Open Issues:  1,847    (🐛)
        👤 Автор:        google
        📊 Активность:   Высокая (обновлён 2 часа назад)
        ```
        - Сделать скриншоты выполнения скрипта
